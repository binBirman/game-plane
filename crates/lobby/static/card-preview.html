零资源纸牌渲染 / 预览

所有样式用 CSS + Unicode ♠♥♦♣，零外部资源。 数据格式：{s: 0..3, r: 0..12}（suit, rank）。

1. 全部 52 张（按花色分行）

2. 内联模式（用于日志 / 玩家标签）

3. 自己手牌（扇形布局，点击切换 selected）

4. 对手手牌（5 人桌，自己是 seat 0）

5. 中央桌面（5 槽，已出牌）

6. 完整组合：对手 + 桌面 + 自己手牌

本页面由 card-render.js + style.css（追加的 .card*）构成， 无图片 / 字体 / 第三方脚本。后续接入 take_your_position 时， app.js 的 renderGame() 会按 game_type 路由到这里。
